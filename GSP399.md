# GSP399 - Network security challenge lab (firewall policy migration, Cloud NAT fix, threat containment)

This challenge combines GSP738, GSP739 and GSP612. Paste the blocks in order in one Cloud Shell tab and stay in the home folder. Every block has the commands and ends with a check line, compare it with the note under the block.

## Known lab traps/bugs (read first)

1. Order matters. This tutorial does Task 2 first, then Task 1, then Task 3. Task 3 creates new firewall rules and Task 1 deletes old ones: do Task 3 before Task 1 is green and its new rules get swept into the migration and deleted.
2. The migration tool cannot add rules to a policy that already exists (same bug as GSP738). After the Phase 1 migration, the policy is deleted and rebuilt with all rules once the tags are mapped.
3. The lab does not tell you the tag names, subnet names or the bastion's name. The blocks read them from the project. Look at the printed values: if one is empty, stop and fix it before going on.
4. Leave the EGRESS rules alone. The cleanup block only removes INGRESS rules, as the lab asks.
5. The checker lags. If a check fails, wait 30-60 seconds and click again.

## Task 2 (do this first). Fix the Cloud NAT gateway

The NAT serves the wrong subnet. Find where private-instance lives and point the NAT there.

```bash
gcloud compute routers list --filter="name=unified-router" --format='value(region.basename())' > ~/region
gcloud compute instances list --filter="name=private-instance" --format='value(zone.basename())' > ~/pzone
gcloud compute instances list --filter="name=private-instance" \
  --format='value(networkInterfaces[0].subnetwork.basename())' > ~/psubnet
gcloud compute routers nats describe unified-nat --router=unified-router --region=`cat ~/region` \
  --format='value(subnetworks[0].name.basename())'
head ~/region ~/pzone ~/psubnet
gcloud compute routers nats update unified-nat --router=unified-router --region=`cat ~/region` \
  --nat-custom-subnet-ip-ranges=`cat ~/psubnet`
gcloud compute routers nats describe unified-nat --router=unified-router --region=`cat ~/region` \
  --format='value(subnetworks[0].name.basename())'
```

You should see the wrong subnet first, then the region, zone and subnet of private-instance, and at the end the NAT pointing at the same subnet as private-instance.

## Task 1. Migrate the firewall rules to a global policy

### 1a. Phase 1: migrate the untagged rules only

The exclusion file is built from the rules that use network tags, so only untagged rules are migrated.

```bash
cd ~
gcloud compute firewall-rules list --filter="network:unified-vpc AND (targetTags:* OR sourceTags:*)" \
  --format='value(name)' > exclude.txt
cat exclude.txt
gcloud beta compute firewall-rules migrate --source-network=unified-vpc \
  --target-firewall-policy=unified-fw-policy --exclusion-patterns-file=exclude.txt --force
gcloud compute network-firewall-policies rules list --firewall-policy=unified-fw-policy --global-firewall-policy \
  --format='table(priority,direction,action,description)'
```

You should see the names of the tagged rules (the ones left out), then the new policy unified-fw-policy with the untagged rules in it.

### 1b. Create secure tags and fill in the mapping file

The tool lists the old network tags. For each one, a secure tag value with the same name is created and written into the mapping file.

```bash
cd ~
gcloud beta compute firewall-rules migrate --source-network=unified-vpc \
  --export-tag-mapping --tag-mapping-file=tag_map.json
gcloud resource-manager tags keys create vpc-tags --parent=projects/`cat ~/project` \
  --purpose=GCE_FIREWALL --purpose-data=network=`cat ~/project`/unified-vpc
cat > fill_map.py <<'EOF'
import json, os, subprocess
proj = open(os.path.expanduser("~/project")).read().strip()
m = json.load(open("tag_map.json"))
for k in m:
    name = k.replace(":", "-").replace("@", "-").replace(".", "-")[:63]
    full = proj + "/vpc-tags/" + name
    subprocess.run(["gcloud", "resource-manager", "tags", "values", "create", name,
                    "--parent=" + proj + "/vpc-tags"])
    r = subprocess.run(["gcloud", "resource-manager", "tags", "values", "describe", full,
                        "--format=value(name)"], capture_output=True, text=True)
    m[k] = r.stdout.strip()
json.dump(m, open("tag_map.json", "w"), indent=1)
print(json.dumps(m, indent=1))
EOF
python3 fill_map.py
```

You should see every old tag paired with a tagValues/ number. If any is empty, stop: paste the block again after 30 seconds (the tag key may not have been ready).

### 1c. Bind the tags, rebuild the policy with all rules, attach it

```bash
cd ~
gcloud beta compute firewall-rules migrate --source-network=unified-vpc \
  --bind-tags-to-instances --tag-mapping-file=tag_map.json
gcloud compute network-firewall-policies delete unified-fw-policy --global --quiet
gcloud beta compute firewall-rules migrate --source-network=unified-vpc \
  --target-firewall-policy=unified-fw-policy --tag-mapping-file=tag_map.json --force
gcloud compute network-firewall-policies associations create --firewall-policy=unified-fw-policy \
  --network=unified-vpc --global-firewall-policy
gcloud compute networks update unified-vpc \
  --network-firewall-policy-enforcement-order=BEFORE_CLASSIC_FIREWALL
gcloud compute network-firewall-policies rules list --firewall-policy=unified-fw-policy --global-firewall-policy \
  --format='table(priority,direction,action,description)'
gcloud compute networks describe unified-vpc --format='value(networkFirewallPolicyEnforcementOrder)'
```

You should see the policy with rules from ALL the old rules (tagged ones included), then BEFORE_CLASSIC_FIREWALL.

STOP: only continue if the policy lists the rules. The next block deletes the old ones.

### 1d. Clean up the old INGRESS rules

```bash
gcloud compute firewall-rules list --filter="network:unified-vpc AND direction=INGRESS" --format='value(name)' > ~/legacy.txt
cat ~/legacy.txt
xargs -n1 -I{} gcloud compute firewall-rules update {} --disabled < ~/legacy.txt
gcloud compute firewall-rules delete `cat ~/legacy.txt` --quiet
gcloud compute firewall-rules list --filter="network:unified-vpc" --format='table(name,direction)'
```

You should see the list of old INGRESS rules, each one updated and then deleted, and at the end only EGRESS rules left (or none).

Check my progress: Migrate legacy firewall rules to a global network firewall policy.

STOP: get this check green before Task 3.

## Task 3. Contain the compromised VM and turn on flow logs

### 3a. Read the facts from the project

```bash
gcloud compute instances list --filter="name=compromised-vm" --format='value(tags.items[0])' > ~/ctag
gcloud compute instances list --filter="name=compromised-vm" --format='value(networkInterfaces[0].network.basename())' > ~/cnet
gcloud compute instances list --filter="name=compromised-vm" --format='value(networkInterfaces[0].subnetwork.basename())' > ~/csubnet
gcloud compute networks subnets list --filter="name=`cat ~/csubnet`" --format='value(region.basename())' > ~/cregion
gcloud compute instances list --filter="name~bastion" --format='value(networkInterfaces[0].accessConfigs[0].natIP)' > ~/bastionip
head ~/ctag ~/cnet ~/csubnet ~/cregion ~/bastionip
```

You should see 5 filled values: the network tag of compromised-vm, its network, its subnet, the region and the bastion's external IP. If the tag or the bastion IP is empty, look at the Setup inventory and write the value by hand, for example `echo "compromised-vm" > ~/ctag`.

### 3b. Deny web traffic, allow SSH from the bastion only, enable flow logs

```bash
gcloud compute firewall-rules create containment-deny-http --network=`cat ~/cnet` \
  --priority=1000 --direction=INGRESS --action=DENY --rules=tcp:80 \
  --target-tags=`cat ~/ctag` --source-ranges=0.0.0.0/0 --quiet
gcloud compute firewall-rules create allow-forensics-ssh --network=`cat ~/cnet` \
  --priority=1000 --direction=INGRESS --action=ALLOW --rules=tcp:22 \
  --target-tags=`cat ~/ctag` --source-ranges=`cat ~/bastionip` --quiet
gcloud compute networks subnets update `cat ~/csubnet` --region=`cat ~/cregion` --enable-flow-logs
gcloud compute firewall-rules list --filter="name~containment OR name~forensics" \
  --format='table(name,direction,sourceRanges.list(),targetTags.list())'
gcloud compute networks subnets list --filter="name=`cat ~/csubnet`" --format='value(name,enableFlowLogs)'
```

You should see both new rules (the SSH one with the bastion IP as its only source) and the subnet followed by True.

Check my progress: Contain compromised workload and enable network telemetry logging.
